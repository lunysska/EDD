# Laboratorio

## Introducción

En esta sección se proporciona la descripción de cada práctica que complementa la teória abordada durante el curso, además, se trabaja con un almacén remoto de ejemplo que el alumno debe replicar, dentro encontrarán las plantillas con el código base para resolver las diferentes prácticas del curso.

En seguida se comparte el enlace al almacén [LeonardoGallo](https://github.com/CCLaboratorio/LeonardoGallo), en específico para este curso las plantillas se ubicarán en la carpeta [edd](https://github.com/CCLaboratorio/LeonardoGallo/tree/main/edd).

Dicho almacén contiene también información relevante para la configuración del entorno de trabajo e irá complementando esta sección.
